I studions meny **Scenmiljö → Bakgrund och ljus → Fotopanorama → Gothic Manor 02** öppnade **Paulinas giv till plats 4** automatiskt `samspel-v2-v4`. Från stol 1 överlappar kortet leken vid utskjutet och handleden skymmer fingerkontakten vid handbytet. Värdesidan syns från båda stolarna i ruta 16. I ruta 22 ligger kortet plant på markeringen, delvis under handen. Blinkningen i ruta 46 syns tydligast framifrån i ansiktsutsnittet jämfört med öppna ögon i rutorna 43 och 51.
